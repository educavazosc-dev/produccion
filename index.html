📋 Cola de producción

Pega directamente desde Excel (columnas: Orden · Modelo · Necesidad · Cantidad). Puedes pegar varias filas a la vez — las columnas se separan por tabulación igual que en Excel. El orden de las tarjetas define la prioridad visible para los técnicos.

🔐 Usuarios y permisos

Las cuentas y contraseñas son administradas centralmente mediante Firebase Authentication. Admin tiene acceso total. Técnico puede realizar movimientos operativos, pero no configurar ni eliminar información.

Para cambiar contraseñas, usa Firebase Console → Authentication → Users.
