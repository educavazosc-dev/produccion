🔐 Usuarios y permisos

Las cuentas y contraseñas son administradas centralmente mediante Firebase Authentication. Admin tiene acceso total. Técnico puede realizar movimientos operativos, pero no configurar ni eliminar información.

Para cambiar contraseñas, usa Firebase Console → Authentication → Users.
